# 金华聚火表格处理

把「订小易」导出的销售订单 / 客户明细，批量转换成「优路达」导入模板的 Windows 桌面工具。

---

## 最新版本：v3.1.2

**下载**：本页 Release 附件 `_v3.1.2_Setup.exe`（约 37 MB）

### 本次修复：匹配明细 0 单 / 输出模板「订单号」列整列空白

该问题自 v3.0.0 起存在，影响所有使用新版「销售订单」导出表头的数据。

- **根因**：新版销售订单表在「订单号」列之后新增了「外部订单号」列。程序按关键字认列时用 `contains("订单号")`，于是「外部订单号」也被当作订单号列，并按列序**覆盖**了真正的订单号列；而「外部订单号」整列为空，导致每行订单号为空、明细匹配被全部跳过（结果面板显示"匹配明细 0 单"），输出文件「订单号」列也是空白。
- **修复**：认列逻辑改为「精确列名优先 → contains 兜底」，已命中的字段不再被后续列覆盖，兜底扫描显式排除含「外部」的列。旧表头（`销售单号`）与新表头（`订单号`）均兼容。
- **实测**（同一份 386 单数据）：

| 指标 | 修复前 | 修复后 |
|------|--------|--------|
| 匹配明细 | 0 / 386 | **386 / 386** |
| 输出「订单号」列非空 | 0 / 231 | **231 / 231** |
| 「异常，请复核」行数 | 54 | 7 |

### 升级方法

1. 下载并运行 Release 中的 `_v3.1.2_Setup.exe`
2. 安装程序会自动识别旧版安装目录并覆盖，**无需先卸载**；D 盘上的表格与日志数据不受影响

> 提示：v3.1.x 客户端自身不含自动更新检查，升级请手动下载安装包。

## 使用前请准备以下文件

| 路径 | 用途 |
|------|------|
| `D:\订单表格\销售订单.xls` | 订单输入（必需） |
| `D:\订单表格\客户经纬度.xls` | 经纬度输入 |
| `D:\订单表格\优路达导入模板.xlsx` | 输出模板（必需） |
| `D:\明细表格\` | 明细输入（可勾选执行后清空） |

运行后会生成 `D:\订单表格\优路达导入模板MMDD-序号.xlsx`，并可一键打开。

## 技术说明

- 界面：PySide6（Qt for Python），支持明暗主题、启动动画、商品明细表格
- 引擎：Rust（calamine 读 .xls/.xlsx、rust_xlsxwriter 写 .xlsx），通过 ctypes 以 DLL 方式直调，零子进程
- 仓库内 `开发文档.md` 为 v1.x 时代的开发文档；`金华聚火表格处理_整合版_fixed.py` 为 v1.3 纯 Python 实现
