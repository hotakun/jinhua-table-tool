# 金华聚火表格处理 — 开发文档 & 版本历史

## 项目概述

金华聚火表格处理是一个 Windows 桌面应用程序，用于将"订小易"系统的销售订单和客户明细批量转换为"优路达"导入模板格式。

### 核心功能
- 明细表格批量处理（读取 .xls → 格式化备注 → 写入 MXBG2）
- 订单表格 8 步流水线处理（读取 → 经纬度匹配 → 明细匹配 → 合并 → 备注重组 → 客户信息 → 模板填充 → 保存）
- 商品明细分类统计（按单位优先排序，交错背景色）
- 实时进度显示 + 结果面板（含经纬度未匹配警告、出库总数）
- 结果导出 TXT 并自动打开生成文件
- GitHub Release 版本自动检测更新

## 技术架构演进

### v1.x 时代：纯 Python
```
tkinter + pandas + openpyxl + xlrd
│
├── 问题: pandas 全家桶导致启动慢 (50MB EXE)
├── 优化: 懒加载 _LazyPandas + --onedir 模式
└── 局限: 分发体积大，启动有加载中延迟
```

### v2.0 时代：Python + Rust 融合
```
Python GUI (ttkbootstrap cosmo)
│
│ ctypes FFI 调用 (零子进程、零命令窗)
▼
Rust DLL (jinhua_engine.dll)
│
├── calamine 读 .xls/.xlsx (纯Rust, 极速)
├── rust_xlsxwriter 写 .xlsx
├── 所有业务逻辑 (明细/订单/统计)
└── 通过 extern "C" 导出, ctypes 调用
```

| 对比 | v1.x Python | v2.0 Python+Rust |
|------|------------|-------------------|
| 启动速度 | ~3s (加载pandas) | <0.5s (无pandas) |
| EXE 体积 | ~50MB | ~8MB + 3MB DLL |
| 窗口出现 | 懒加载优化后秒出 | 秒出 |
| 核心处理 | pandas | Rust calamine (更快) |
| 通信方式 | - | FFI 直接调用 |
| 无命令行窗口 | --noconsole | 天然无窗口 |

## v2.0 架构详解

### Python 侧 (GUI)
- **框架**: tkinter + ttkbootstrap (cosmo 主题)
- **通信**: ctypes.CDLL 加载 Rust DLL
- **进度回调**: CFUNCTYPE 回调函数指针传给 Rust
- **排版**: 所有文本格式/空行/标红 由 Python `_build_result_message()` 控制
- **GUI 组件**: `ttk.Button(bootstyle=SUCCESS)`, `ttk.Progressbar(bootstyle="success-striped")`

### Rust 侧 (引擎 DLL)
- **导出函数**: `engine_process(delete, stats, callback)` → JSON
- **导出函数**: `engine_free(ptr)` 释放内存
- **依赖**: calamine 0.26 (读), rust_xlsxwriter 0.79 (写), chrono 0.4 (日期)
- **编译**: `crate-type = ["cdylib"]` 产生 .dll
- **进度回调**: 通过 `static mut CALLBACK: Option<ProgressCb>` 调用 Python 函数

### 数据流
```
用户点"执行"
  → Python 后台线程调用 engine_process()
  → Rust 处理, 实时调用 callback(pct, label)
  → Python 更新进度条 / 接收 stats 数据
  → Rust 返回 {"file":"...","orders":48,...}
  → Python _build_result_message() 排版
  → 显示结果面板 + 商品明细统计
```

### 版本检测
```
启动后 2s → GitHub API → 获取最新 tag_name
→ 数值比较 (2.0.0 > 1.3?) 
→ 有新版 → 弹窗提示下载
→ 双击标题栏 → 手动检查更新
```

- Python 3.13+ (推荐 3.14)

- ttkbootstrap

```powershell

copy target\release\jinhua_engine.dll D:\WFR\D2Y\jinhua_engine.dll
```

```powershell
cd D:\WFR\D2Y
python -m PyInstaller --noconsole --onedir --name JinhuaH --icon favicon.ico --add-data "favicon.ico;." --add-data "jinhua_engine.dll;." 金华聚火表格处理_hybrid.py
```

1. 安装 Inno Setup
2. 右键 `setup_hybrid.iss` → Compile

3. 已安装的程序启动后自动检测更新

## API 参考

### Rust DLL 导出函数

```rust
// 执行完整处理流程, 返回 JSON 字符串指针
// delete: 是否删除源文件 (0/1)
// stats: 是否统计商品明细 (0/1)
// cb: 进度回调函数
#[no_mangle]
pub extern "C" fn engine_process(
    delete: u8,
    stats: u8,
    cb: ProgressCb,
) -> *mut c_char;

// 释放 engine_process 返回的字符串
#[no_mangle]
pub extern "C" fn engine_free(ptr: *mut c_char);
```

### 返回 JSON 格式
```json
{
    "file": "优路达导入模板0523-9750.xlsx",
    "orders": 48,
    "customers": 42,
    "matched": 48,
    "products": 890,
    "no_coords": ["美丽烤包子", "地摊鲜货烧烤", ...],
    "path": "D:\\订单表格\\..."
}
```

### 进度回调
```
CALLBACK = ctypes.CFUNCTYPE(None, ctypes.c_uint32, ctypes.c_char_p)
# pct: 0-100, label: 进度描述字符串
# label 特殊前缀 "STATS:total|lines" 表示商品统计数据
```

## 已知限制

1. 硬编码 D 盘路径
2. 仅支持 .xls/.xlsx 格式
3. Windows 专用 (依赖 os.startfile)
4. 依赖联系信息列格式 `名称-手机号`
5. Rust 引擎单线程处理
6. 无 i18n 多语言支持
