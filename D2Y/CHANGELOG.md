# 金华聚火表格处理 v2.0.0 发行说明

## 重大升级：Python + Rust 融合架构

### 启动速度大幅提升
- 彻底移除 pandas 依赖，程序启动**几乎瞬间**出窗口
- 不再有"加载中..."等待阶段
- Rust 引擎负责全部 Excel 处理，速度比 Python 快 3-5 倍

### 全新界面
- 采用 ttkbootstrap cosmo 主题，现代扁平风格
- 绿色条纹进度条，视觉反馈更清晰
- 按钮语义色（绿色=执行、红色=关闭）
- 结果面板集成商品明细统计（单位优先分组，交错背景色）

### 技术亮点
- Rust DLL 通过 FFI 直接调用，零子进程开销
- 无命令行窗口闪烁
- 安装包仅 15MB，比旧版减小 70%

### 更新内容
- 双击标题栏版本号手动检查更新
- 安装包自动识别旧版安装路径，无缝升级
- 未匹配经纬度客户列表红色标注
- 结果自动导出 TXT，一键打开生成文件

---

## 升级说明

1. 下载 `金华聚火表格处理_v2.0.0_Setup.exe`
2. 直接安装，会自动识别旧版安装位置
3. 无需卸载旧版，覆盖安装即可
